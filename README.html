statPresentation：股票日報酬是常態嗎？±kσ 會低估多少極端波動？

115-1 程式設計與統計軟體 分組期末專題（資料分析路線）。

專題問題

Ticker Volatility 活頁簿會畫出 ±1/2/3 SD 區間。若把它讀成常態機率（68% / 95% / 99.7%），等於假設日報酬服從常態且彼此獨立。本專題回答：

股票日報酬是否服從常態分布？若否，用 ±kσ 判斷「極端波動」會低估多少機率？改用 Student-t 分布或歷史分位數能不能改善？（前 70% 期間估參數、後 30% 驗證）

標的：SPY（decisions.md D-08），價格用 Yahoo 含息調整價 adjclose（與活頁簿相同）。主要發現：最近 200、500、2,000 個交易日三視窗皆拒絕常態；超出 3σ 的天數是常態預期的 5–6 倍，樣本外（2,000 日切 70/30）常態低估 3σ 極端日約 3.7 倍，t 分布與歷史頻率未被拒絕；前一日 VIX 偏高時 2σ 極端日比例 17.8% vs 1.3%。詳見 docs/results.md，書面報告 report/Report.docx（PDF 同版）。

本專題為雙主軸：（一）產品——Ticker Volatility 活頁簿本身，原始碼在 product/，可用 product/build.ps1 從原始碼建出；（二）研究——檢驗活頁簿的 SD 區間能否當常態機率讀。超出 3σ 的極端日只佔約 1.5% 的交易日，卻貢獻 28–40% 的總波動（常態下約 2.9%）。2330.TW 為早期流程驗證，保留作測試紀錄。

環境

  • 開發環境：Windows 11、Python 3.14.4、R 4.6.1（另需 R 內建的 MASS 與 jsonlite）。
  • Python： `` python -m venv .venv .venv\Scripts\activate # macOS/Linux: source .venv/bin/activate pip install -r requirements.txt ``
  • R：只用 base R＋MASS＋jsonlite，版本資訊在 r/sessionInfo.txt。尚未建立 renv.lock（見「已知問題」）。
  • 活頁簿對帳（選用）：需 Windows＋Excel。腳本以 AutomationSecurity = 1（允許巨集）開啟活頁簿執行 RunVT，請只對自己信任的活頁簿副本使用。
