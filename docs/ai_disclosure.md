## 重要錯誤修正與高風險輸出查核

1. **資料錯誤（D-04）**：AI 寫的整合程式比對出 Yahoo 在 2026-10-23（TWSE 無交易）多一根陳舊 K 棒。
   查核方法：直接讀 TWSE 原始 JSON 確認該月日期序列，再改程式並重驗。
2. **測試判準錯誤（D-03）**：AI 寫的稀有事件測試容差在統計上不合理，改以二項檢定判準；種子未更動。
3. **AI 數字的獨立查核**：所有統計量由 R（不同語言、不同函式庫）重算 44 項（SPY；2330 舊版 26 項）；
   活頁簿數字由 Excel 實際執行 VBA 取得，與 Python 複製版比對（docs/workbook_check.md）。
   **不以 AI 自稱「已通過」作為證據**，以上皆有輸出檔可查。
