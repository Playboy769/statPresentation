# 與 Ticker Volatility 活頁簿對帳

目的：確認本專題的數字就是使用者在活頁簿上看到的數字，結論才能說是「根據 Ticker Volatility」。

## 方法

1. 讀活頁簿 VBA 原始碼（`VT/modVT.bas` 的 `DrawPage`），把日線 SD 區塊的算法寫成
   `python/workbook_replica.py`：
   - 價格：Yahoo **adjclose**（`FetchYahooSeries` 有 adjclose 就用，見 debug_log D-07）
   - 樣本：最近 max(520, PERIOD) 筆簡單報酬（日線最多 MAXN = 2600 根）
   - 視窗：最近 PERIOD 筆，SD 用 n−1
   - 「超過 2 SD」：視窗內 |r − 視窗平均| > 2·SD 的天數
   - 「DAYS INSIDE」：全樣本 |r| ≤ k·SD 的比例（注意：活頁簿**沒有減平均**）
2. 複製一份活頁簿到暫存資料夾（**原檔不動**），用 Excel COM 隱藏執行：
   B2＝代號、B3＝PERIOD、E3＝D，執行 `RunVT`，讀回 C8、M10:M12、P10:P12。
3. 同一時間抓 Yahoo 資料，用複製版計算後比較。

## 結果：SPY，PERIOD 200／500／2000（2026-11-24，主分析）

| PERIOD | 活頁簿 SD | Python SD | 超過 2 SD（活頁簿／Python） | ±1／2／3 SD 內（活頁簿＝Python） |
|---|---|---|---|---|
| 200 | 1.00% | 1.0009% | 7 / 7 | 0.775 / 0.953846 / 0.984615 |
| 500 | 1.10% | 1.1027% | 18 / 18 | 0.817308 / 0.963462 / 0.986538 |
| 2000 | 1.22% | 1.2240% | 90 / 90 | 0.8035 / 0.9555 / 0.9855 |

全部完全一致（以 adjclose 計算）。原始輸出：`docs/evidence/workbook_vs_python_SPY_20261124.json`。
第一次對帳用 close 時，±1 SD 內差 1–5 天，因而發現活頁簿讀的是 adjclose（debug_log D-07）。

## 注意

- 活頁簿的 SD 用 PERIOD 視窗、DAYS INSIDE 用 520 筆全樣本，且 DAYS INSIDE 不減平均；
  本專題主分析（`analyze.py`）用訓練期平均與 SD，兩者口徑不同，**不要直接拿兩邊數字相比**。
- 資料是當天下載，隔天重跑數字會變；對帳的重點是「同一份資料、同一套算法得到同一個數字」。
